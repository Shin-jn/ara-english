# 영어 놀이터 🐱 (English Playground)

초등 2학년 아이를 위한 영어 단어·문장 퀴즈 웹앱입니다.
`data.xlsx`(단어/문장 시트)를 **브라우저에서 직접 읽어** 퀴즈를 자동으로 만들어 줍니다.

---

## 🎯 무엇을 할 수 있나요?

- **단어** — 낱말 카드(학습) / 뜻 맞히기 / 영어 맞히기 / **듣고 맞히기** / **단어 쓰기(직접 타이핑)**
- **문장** — 문장 카드(학습) / 뜻 맞히기 / **문장 만들기(단어 순서 배열)** / 빈칸 채우기 / **문장 쓰기(직접 타이핑)**

> ✏️ **쓰기 모드**: 뜻을 보고 영어를 직접 타이핑해요. 💡힌트로 글자를 하나씩 볼 수 있고,
> 대소문자·마침표·띄어쓰기는 조금 틀려도 정답으로 인정해줍니다.
- 🔊 **발음 듣기**: 버튼을 누르면 영어 원어민 발음이 나와요 (브라우저 내장 기능, 설치·비용 없음)
- ⭐ 정답마다 별 획득, 폭죽 효과, 고양이 마스코트 응원, 점수 저장

---

## ✏️ 내용 추가·수정하는 법 (가장 중요!)

1. **`data.xlsx`** 파일을 엽니다.
2. `단어` 시트 또는 `문장` 시트에 줄을 추가합니다.
   - 형식은 그대로 두세요: `No. | 단어(또는 문장) | 뜻`
3. 저장하고 **엑셀을 닫습니다.** (닫아야 파일이 잠기지 않아요)
4. 아래 "배포하기"대로 폴더를 다시 올리면 **퀴즈에 자동 반영**됩니다.

> 코드는 손댈 필요가 전혀 없어요. 엑셀만 바꾸면 됩니다.
> 시트 이름(`단어`/`문장`)과 열 제목(`단어`/`문장`/`뜻`)만 유지해 주세요.

---

## 🚀 배포하기 (Netlify)

> ⚠️ **중요:** 이 폴더에는 `netlify.toml` 같은 빌드 설정 파일이 **없어야** 합니다.
> 그런 설정이 있으면 Netlify가 "빌드가 필요한 사이트"로 오해해서 빈 페이지(404)를 올립니다.
> 이 폴더는 설정 없이 그대로 올리면 되는 순수 정적 사이트입니다.

### 방법 A — 폴더 드래그 (가장 쉬움)
1. https://app.netlify.com/projects/frabjous-basbousa-0c3603/overview 접속
2. 왼쪽 메뉴 **Deploys** 탭으로 이동
3. 이 **`sight words` 폴더 자체를** 화면의 "Drag and drop your site output folder here" 영역에 **드래그 앤 드롭**
   - (폴더 안의 `index.html`이 사이트 첫 화면이 됩니다)
4. 업로드가 끝나면 `https://araenglish.netlify.app/` 를 새로고침 → 앱이 뜨면 성공!

내용을 바꿀 때마다 → 엑셀 저장·닫기 → 폴더를 다시 드래그하면 갱신됩니다.

### 방법 B — Netlify CLI (더 확실함)
```
npm install -g netlify-cli
netlify login
netlify deploy --prod --dir "." --site araenglish
```

### ✅ 배포가 잘 됐는지 확인
- `https://araenglish.netlify.app/index.html` 가 열리면 정상.
- "Page not found"(404)가 뜨면 → 파일이 루트에 안 올라간 것.
  폴더 **안의 파일들이 바로 보이는 상태**에서 폴더째 다시 드래그하세요.
  (폴더의 부모 폴더나, 폴더를 감싼 또 다른 폴더를 올리면 안 됩니다.)

## 📱 사용 팁

- **태블릿(아이패드)** 가로/세로 모두 잘 보이도록 만들었어요. 큰 버튼이라 아이가 누르기 쉬워요.
- 발음이 안 나오면 태블릿 **무음 스위치**를 해제하고 화면을 한 번 눌러 주세요. (브라우저 정책상 첫 터치 후 소리가 나옵니다)
- Safari / Chrome 최신 브라우저 권장.

---

## 📂 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 파스텔 여아 감성 디자인 + 고양이 마스코트 |
| `app.js` | 엑셀 읽기·퀴즈·발음·보상 로직 |
| `lib/xlsx.full.min.js` | 엑셀을 읽는 라이브러리(SheetJS) |
| `data.xlsx` | **여기에 단어/문장을 추가하세요** |

> 💡 `~$data.xlsx` 같은 파일이 보이면 엑셀이 열려 있을 때 생기는 임시 파일이에요. 무시해도 되고, 엑셀을 닫으면 사라집니다.
